# ADR-0004 — Frozen Decision Record, not operating report

- **Status:** ACCEPTED AS DESIGN REQUIREMENT, VS01-007.
- Existing frozen exporter covers one accepted decision revision with historical ancestry, not later action execution status.
- VS-01 will name it **Frozen Decision Record**, include evidence cutoff/rights and revision IDs, and show independently timestamped current action state in the UI.
- Cross-object consistent executive package and DOCX/PDF are separate owner-gated work; never claim present implementation.
