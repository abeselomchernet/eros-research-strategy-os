# ADR-0003 — Synthetic positive and WDI restricted lanes

- **Status:** ACCEPTED AS DESIGN REQUIREMENT, VS01-005.
- Positive offline fixture must have documented creation/ownership/allowed-use, explicitly synthetic identities and numeric observations, no false data source claims.
- Real archived WDI is genuine public data with source attribution and capture identity but export-rights evidence must be independently qualified; test entry `PERMITTED` is not proof of licence.
- Source acquisition is disabled in this milestone. Any numeric importer has a synthetic-only mode and cannot promote to actual observations.
